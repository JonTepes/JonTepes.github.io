IoT digital twin (factory model)

  • Back to projects

I built this project for my Bachelor's thesis. It is a miniature factory built on Industry 4.0 principles that connects physical mechanisms with a digital control system (a digital twin).

Demo

How it works

  • Hardware: a 3D-printed crane, two conveyor belts, sensors that locate metal blocks and colour sensors for sorting.
  • Control: microcontrollers connected over MQTT to a central node (Raspberry Pi).
  • Software: a Node.js backend with an interactive 3D interface (Three.js) for monitoring and controlling the machines in real time. I used AI tools to help with coding and integration.
